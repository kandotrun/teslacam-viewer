# TeslaCam Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SSD上のTeslaCamフォルダをブラウザで選択し、セントリー、保存済み、最近の走行をイベント単位で整理して6カメラ同期再生できるWebアプリを`teslacam.2-38.com`へ公開する。

**Architecture:** React SPAがフォルダ走査、TeslaCam解析、Blob URL生成、同期再生をブラウザ内で完結させる。Viteと`@cloudflare/vite-plugin`がReactクライアントとHono Workerを一つのCloudflare Workersデプロイへ統合し、Honoは`/api/health`、Workers Static AssetsはVite成果物を配信する。

**Tech Stack:** React 19.2.8、TypeScript 7.0.2、Vite 8.2.2、Hono 4.13.3、Cloudflare Vite Plugin 1.53.1、Wrangler 4.125.0、Zod 4.4.3、Vitest 4.1.11、Testing Library、Playwright 1.62.1、ESLint 10.8.1

**Spec:** `docs/superpowers/specs/2026-08-21-teslacam-viewer-design.md`

## Global Constraints

- 実際のTeslaCam映像、サムネイル、JSON、ファイル名一覧、住所、座標をGitへ追加しない。
- 選択したローカルファイルをWorker、外部API、解析サービスへ送信しない。
- `any`、`as any`、`@ts-ignore`、`@ts-expect-error`、二重キャストを使用しない。
- 実装コードへコメントを書かない。
- `useEffect`はメディア要素とObject URLのライフサイクル管理に限定する。
- Cloudflare Bindings型は`wrangler types`で生成し、手書きしない。
- UI文言は日本語とし、Teslaのロゴや公式UIを模倣しない。
- `DESIGN.md`をUI実装前に作成し、色、余白、書体、角丸、影、動き、アクセシビリティ制約を実装の契約にする。
- セキュリティヘッダーは静的アセットとHonoレスポンスの両方へ適用する。
- 実装の各コミット前に対象テストと`npm run typecheck`を通す。
